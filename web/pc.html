LocalDrop

휴대폰 카메라로 찍으세요

같은 와이파이에 연결된 폰에서 열려요. 폰에 앱을 설치하지 않아도 돼요.

연결된 기기

    받은 파일 저장 위치

    폰과 주고받은 것이 여기에 쌓여요

    폰에서 사진이나 파일을 보내면 저장 폴더에 바로 들어가고, 여기서 열 수 있어요.
    폰으로 보낼 파일은 이 창에 끌어다 놓거나 아래 클립 버튼을 누르세요.

    놓으면 폰으로 보내요 폰 화면에 바로 나타나요

    설정

    받은 파일 저장 위치
    연결 초기화 새 QR 코드를 만들어요. 지금 연결된 폰은 새 QR을 다시 찍어야 해요.
    주고받은 기록 지우기 목록만 비워요. 저장 폴더에 받은 파일은 지우지 않아요.

    폰에서 안 열릴 때

    위에서부터 하나씩 확인해 보세요.

    1. 같은 와이파이인지 확인해요. 폰의 와이파이가 꺼져 있거나 LTE/5G로 바뀌어 있으면 PC에 닿지 않아요.
    2. Windows 방화벽에서 LocalDrop을 허용해요. 처음 실행할 때 뜬 '액세스 허용' 창에서 허용을 누르지 않았다면, 아래 버튼으로 다시 설정할 수 있어요. 관리자 권한을 묻는 창이 뜨면 '예'를 누르세요.
    3. 네트워크 종류를 '개인'으로 바꿔요. Windows 설정 → 네트워크 및 인터넷 → 와이파이(또는 이더넷) → 지금 연결된 네트워크에서 '개인 네트워크'를 고르세요.
    4. 공유기의 게스트 와이파이를 피해요. 게스트 네트워크나 'AP 격리(기기 간 통신 차단)'가 켜진 와이파이에서는 기기끼리 연결되지 않아요.
    5. VPN을 잠시 꺼요. VPN이 켜져 있으면 PC 주소가 달라질 수 있어요.
    6. 다른 주소를 골라 봐요. PC에 네트워크가 여러 개 있으면 QR 아래 '다른 주소로 바꾸기'에서 바꿀 수 있어요.

    LocalDrop을 종료했어요

    이 탭은 닫아도 돼요. 다시 쓰려면 LocalDrop.exe를 실행하세요.
